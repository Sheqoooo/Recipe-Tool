Automatisch auf Deutsch aufbereiten

Mit deinem OpenAI-API-Key übersetzt Rezeptwerk Rezepttext und bringt Zutaten, Mengen und Schritte in eine einheitliche Form.

Bei einem KI-Import wird der ausgelesene Rezepttext an OpenAI gesendet. Sammlung und Einkaufsliste bleiben lokal. Die API wird separat von ChatGPT Plus nach Verbrauch berechnet.

Der Schlüssel wird lokal gespeichert und nicht im Browser hinterlegt. Bitte nicht in einen Chat oder ins Repository kopieren.
