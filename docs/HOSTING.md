# Hosting

Ziel ist Cloudflare Workers + D1 + Access. Die vollständige aktuelle Anleitung steht in [DEPLOYMENT.md](../DEPLOYMENT.md).

Kein VPS oder Docker erforderlich. Eine bestehende produktive D1 ist bereits manuell angelegt; Name und ID müssen in der Konfiguration ergänzt werden. Es werden keine Ressourcen oder Migrationen automatisch angelegt. GitHub Pages bleibt als öffentliche statische Vorschau bestehen.
